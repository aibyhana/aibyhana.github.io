# About

This is where I keep what I learn. Each note is about one idea, written in my own words, and the notes link to each other.

Nothing here is finished. I come back to notes and change them when I understand something better, so the date beside a note is the day I last touched it.

## How to read it

- A ring, half a dot or a full dot in front of a title says how far along the note is: a first thought, still growing, or settled.
- A link with a dashed line under it points to a note I have not written yet.
- Beside every note is a list of the notes that link to it. Following those is often more useful than the note itself.
- The search box looks through all the text. Press `/` to jump to it.

The way of working comes from the Zettelkasten.

## How it is made

Every note is a plain text file. The site is built from those files.
